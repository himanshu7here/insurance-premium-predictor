# insurance-premium-predictor

# 💡 Insurance Premium Prediction

## 📌 Overview
This project predicts insurance premium costs based on individual health and demographic factors using machine learning techniques. The goal is to enable personalized and data-driven insurance pricing.

---

## 🚀 Live App
🔗 https://insurance-premium-predictor-ipp.streamlit.app/

---

## 📊 Problem Statement
Insurance companies often rely on traditional actuarial methods, which fail to capture individual risk variations. This project leverages machine learning to predict premiums more accurately using personal health data.

---

## 📂 Dataset Features
- Age  
- Diabetes  
- Blood Pressure Problems  
- Chronic Diseases  
- Surgeries  
- Height & Weight (BMI)  
- Allergies  
- Family Cancer History  

---

## 🔍 Approach

### 1. Exploratory Data Analysis (EDA)
- Distribution analysis  
- Correlation heatmap  
- Outlier detection  

### 2. Hypothesis Testing
- T-tests and ANOVA to validate feature impact  

### 3. Feature Engineering
- BMI calculation  
- Risk Score creation  

### 4. Model Building
- Linear Regression (baseline)  
- Random Forest (final model)  

### 5. Model Evaluation
- RMSE  
- R² Score  

### 6. Model Explainability
- Feature Importance  
- SHAP analysis
